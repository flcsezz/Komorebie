## 🌟 Welcome to Komorebie

**Komorebie** is more than just a productivity app—it's a digital Zen garden designed to help you reclaim your focus in an increasingly noisy world.

Driven by the philosophy of "Komorebi" (the Japanese word for sunlight filtering through trees), this application combines serene aesthetics, a distraction-free interface, and powerful analytics to create the ultimate deep-work environment.

---

## ✨ Features

- 🧘 **Absolute Focus Mode**: A hard constraint on design—no unnecessary UI, motion, or social noise while you work.
- 🎨 **Zen Customization**: Custom color-tagged tasks and sessions with beautiful, synced donut charts.
- 📊 **Deep Analytics**: Flow analytics and session tracking synced flawlessly across devices using Edge computing.
- 🌌 **3D Sanctuary**: An immersive environment powered by React Three Fiber (R3F) to help you get into the zone.
- ☁️ **Real-time Sync**: Hybrid cloud sync via Supabase and Cloudflare Workers ensuring your flow is never interrupted.

---

## 🛠️ Tech Stack

Built with cutting-edge tools to ensure blazing fast performance and a buttery smooth user experience:

- **Frontend Core**: Vite, React 19, React Router, TypeScript
- **Styling & Motion**: Tailwind CSS v4, Framer Motion
- **3D Experiences**: React Three Fiber (R3F)
- **Backend & Auth**: Supabase
- **Edge Compute**: Cloudflare Workers

---

## 🎨 The Zen System

The entire user interface is governed by the **Zen System**. This means:
- **Calm over loud**: Soft, glassmorphic UI elements that blend into the background.
- **Convenience over clutter**: Essential tools exactly when you need them.
- **Focus over engagement**: We actively design *against* infinite scrolling or addictive loops.
